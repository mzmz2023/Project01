# docs — 项目文档

## 职责

存放项目核心文档，包含接口规范、架构设计等团队契约类文档。

## 文件说明

| 文件 | 说明 | 维护人 |
|------|------|--------|
| `api-spec.md` | API 接口规范文档，定义前后端所有接口的请求/响应格式 | member C（后端） |
| `model_report.md` | 模型评估报告，记录算法选型、超参数、离线指标及训练环境 | member B（算法） |

## 维护原则

- 所有文档在团队达成共识后锁定，修改需通知相关方
- `api-spec.md` 是前后端联调的核心契约，代码实现必须与之一致
- `model_report.md` 中的离线指标在每次模型重新训练后同步更新
